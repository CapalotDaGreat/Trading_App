# TradeAcademy progress model

Progress counts learning and process work, not how many simulated trades the user took.

## Evidence sources

| Source | What it contributes |
| --- | --- |
| Academy progress | Read, practised, quiz, concept misses |
| Practice attempts | Domain accuracy and repeated misses |
| Journal | Review quality and process discipline |
| Simulation decisions | Thesis, invalidation, close reviews |
| Replay TV | Process skills (existing Replay skill map) |
| Trading DNA / PI | Longitudinal traits from stored records only |

## Outputs

- Skill domain scores with evidence level
- Home training chain
- Weekly plan (`buildWeeklyTrainingPlan`)
- Training readiness (never a live-trading certificate)

Do not invent traits. If evidence is `none`, say so.
