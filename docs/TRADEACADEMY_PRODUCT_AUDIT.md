# TradeAcademy competence audit

**Date:** 10 September 2026  
**Question:** Does this application actually make the user better prepared for real-world trading?

Judged by whether features improve trading competence — not by feature count.

## Verdict

A disciplined user who follows **Today's Training** for months can leave with better **risk language, uncertainty habits, thesis/invalidation writing, chart structure, and process review**. The app does **not** certify live trading, and it should not.

The spine is a training system: Learn → Practice → Replay → Simulate → Journal → Review → evidence-based next practice. That loop is now sequential on the main surfaces. It is **not** yet a closed assignment: the queue can be skipped, and simulation/journal evidence is only partly bound to concept mastery.

Readiness language is honest: strengths and areas to improve from demonstrated work. Simulated P/L does not grade a decision. The product will never say the user is ready to trade real money.

## What this pass changed

- Readiness uses drill accuracy and caps thin samples. Paper fills without close reviews do not max “simulation behavior.”
- Home is a coach: Foundations (if new) → Today's Training → process-first simulation. Beginners do not see an event stack. Equity is not the simulate headline.
- Loop CTAs are sequential: Learn → Practice → Replay → Simulate → Journal → Review.
- Practice miss → related lesson. Practice hit → Replay / Simulate / Journal.
- Review's primary next step is the learning-engine focus area.
- Simulate → Journal carries thesis and invalidation into notes.
- Beginner/unspecified experience: Events tab hidden (`href: null`). Events screen is a foundations lesson, not a news feed.
- `fund-calendar`, `dec-invalidation`, and `risk-position-sizing` now have objectives, examples, counterexamples, limitations, charts, exercises, concept-tagged quizzes, and sim/event links.
- Event importance copy says “area to improve,” not “weakness.”

## Residual gaps (competence, not cosmetics)

1. **Today's Training is still skippable.** Skip/defer do not require a demonstrated retry. A user can graze features for six months without closing a weakness.
2. **Simulation and journal are weakly bound to concept mastery.** Thesis text is handed to the journal; it does not automatically credit `invalidation` or `position-sizing` until a tagged quiz/drill/exercise fires.
3. **Replay TV timestamps are educational.** Rooms are diverse and bounded, but candle years are not always the advertised historical year. Licensed tapes are not purchased.
4. **Some classic lessons remain thinner** than the flagship template (objectives / chart / exercise / limitation).
5. **Advanced longevity** after hundreds of sessions is not proven. Adaptation exists; it is not a spaced mastery contract.

## Trust invariants (must hold)

- No “you are ready to trade real money.”
- Simulated results labelled simulated. Simulated P/L is context, not a grade.
- External events: source link + freshness (delayed / sample / cached).
- Historical rooms: known information boundary; outcomes are not the sole score.
- Every readiness number names its evidence or says evidence is insufficient.

## Do not build

Brokerage, live signals, social copy-trading, or a noisy news feed. Those would make the product look busier and make the user worse prepared.
